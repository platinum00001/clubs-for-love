# Clubs for Love — Cape Cod

Used or new golf clubs on Cape Cod become a first bag for someone in recovery. Donors give gear
(photo → pickup or drop-off), people in recovery / coaches / houses ask for clubs, and courses,
shops and simulators donate or sponsor a round. A Root to Rise program.

**Live:** https://platinum00001.github.io/clubs-for-love/ (GitHub Pages, deploys on every push to `main`)

## What's here
- Static HTML/CSS/JS — no build step needed to host. Pages are generated by `tools/build.py`
  (shared header/footer, OG tags, Our Sites list). Edit a page body in `tools/build.py`, then run
  `python3 tools/build.py` and commit the regenerated `*.html`.
- `config.js` — the ONLY place for the contact email, Supabase URL/publishable key, schema and social links.
- `supabase/schema.sql` — database (schema `clubs4love` in project james-sites) with Row Level Security.
- Forms (donate, pickup, need clubs, drop site, give a round, contact) save to Supabase with photos in
  a private bucket; if online saving isn't available they fall back to a pre-filled email.
- Accounts (optional): email magic link, password, Google and Facebook ("coming soon" until enabled).
  Account page: profile, my forms, my event interest, delete my data. Staff page for admins.
- Privacy (with `#data-deletion`) and Terms pages; OG/Twitter share image; favicons + web manifest.

## Run locally
```
python3 -m http.server 8080   # from the parent folder, open http://localhost:8080/<folder>/
node tests/paths.test.js      # sub-path-safe links, no secrets, OG tags, Our Sites, privacy anchor
```
Headless check: `npm i puppeteer-core && node tools/smoke.js <baseURL> shots`.
